# 指纹浏览器保存的账号密码安全吗？

用「指纹浏览器」分开工作环境，并不自动回答密码如何加密、哪些数据参与同步或谁能解锁设备。涉及客户账号时，先分清保存的密码、仍然有效的网站登录会话、以及客户端账号这三样东西。

## 为什么没看见密码也可能能进后台？

网站可以用 Cookie 维持登录。即使同事不知道密码，只要能进入一个仍有有效会话的窗口，可能就能看到后台。桌面客户端的「网页与数据」菜单是核对当前环境数据的入口；清理前先确认影响范围。
[官网操作说明](https://zwbrowser.com/help/desktop/privacy/)

## 交班时怎样保住控制权？

给同事自己的授权业务身份，按岗位分配权限；共享电脑设置独立系统账户和锁屏。遇到凭据泄露，应从网站端修改密码并检查有效会话、恢复方式及二次验证。涉及公司密码库、加密或备份要求时，以当前版本的正式说明和单位政策为准。
